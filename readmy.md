# Raspberry Pi 5 CNC Bridge for Candle & GRBL

Скрипт та міст для синхронізації програмного забезпечення Candle з апаратними пінами GPIO на Raspberry Pi 5 (для керування реле шпинделя M3, M4, M7, M8 без затримок).

## Встановлення в один рядок на Raspberry Pi:

Виконайте в терміналі команду для клонування та запуску встановлювача:

```bash
git clone [https://github.com/ВАШ_ЛОГІН/pi-cnc-bridge.git](https://github.com/ВАШ_ЛОГІН/pi-cnc-bridge.git)
cd pi-cnc-bridge
./install.sh
